## Features

- 🧠 **AI-Generated Docs** — Powered by Groq LLaMA for fast, high-quality Markdown
- 📐 **Architecture Diagrams** — Auto-generated Mermaid flowcharts with dark theme
- 📦 **Module Breakdown** — Per-module explanations with design rationale
- 📖 **API Reference** — Interfaces, entry points, and usage guidelines
- 🌐 **Live Preview** — Instantly view and browse the generated MkDocs site
- 🎨 **Premium Frontend** — Animated dark UI with particle canvas and timeline loader

## Quick Start

### 1. Install Dependencies

```bash
pip install fastapi uvicorn groq python-dotenv mkdocs mkdocs-material pymdown-extensions gitpython
```

### 2. Set Environment Variables

Create a `.env` file in the root:

```env
GROQ_API_KEY=your_groq_api_key_here
```

### 3. Start the Backend

```bash
cd backend
python -m uvicorn api:app --host 0.0.0.0 --port 8000 --reload
```

### 4. Open the Frontend

Navigate to: **http://localhost:8000/ui/**

### 5. Generate Docs

Paste any GitHub URL (e.g. `https://github.com/username/repo`) and click **Generate**.

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/generate-docs` | Start doc generation for a repo |
| `GET`  | `/api/status/{id}` | Poll generation status |
| `GET`  | `/api/preview/{id}` | View the generated MkDocs site |
| `GET`  | `/api/download/{id}` | Download docs as `.zip` |
