# Project Overview
================

## Project Title & High-Level Purpose
------------------------------------

The project is a simple game implemented using the Turtle graphics library in Python.

## Core Features
----------------

*   A simple game with two players, each with their own turtle
*   Players take turns moving their turtle and firing projectiles towards each other
*   Game increments score for the player who hits the other player's turtle
*   Game continues until one player reaches a score of 200

## Technology Stack
-------------------

*   **Python**: The primary programming language used for the project
*   **Turtle Graphics Library**: Used to create the game environment and handle user input
*   **Random Module**: Used to generate random numbers for the game
*   **Math Module**: Used for mathematical operations

## Getting Started / Quick Start
-------------------------------

To get started with the project, follow these steps:

1.  Install the required libraries by running `pip install turtle`
2.  Run the `Chase.py` script using Python (e.g., `python Chase.py`)

## Folder / Component Structure Summary
-----------------------------------------

The project consists of a single file, `Chase.py`, which implements the game logic. The file uses the Turtle graphics library to create the game environment and handle user input.

Note: The project structure is simple and straightforward, with all the game logic implemented in a single file. As the project grows, it may be beneficial to refactor the code into separate modules or classes to improve maintainability and scalability.
